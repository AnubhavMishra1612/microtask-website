# Verify Before Done

- Inspect the relevant code and identify the root cause.
- Make the smallest complete fix.
- Run targeted tests and available type and lint checks.
- Fix regressions before proceeding.
- Never claim a test passed unless it was actually run.
- Report changed files, checks performed, results, and blockers.
- Stop when the requested milestone is complete.
