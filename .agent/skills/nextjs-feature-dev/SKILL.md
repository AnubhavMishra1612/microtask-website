# Next.js Feature Development

- Inspect relevant files before editing.
- Reuse existing components, utilities, and dependencies.
- Prefer Server Components unless client-side interaction is required.
- Use strict TypeScript and validate untrusted input.
- Keep changes small and scoped to the requested feature.
- Avoid unnecessary packages and duplicate code.
- Follow the existing design system and responsive layout.
- Run relevant lint, type checks, and tests after changes.
- Report changed files and actual verification results.
